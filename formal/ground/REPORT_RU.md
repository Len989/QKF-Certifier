## Граница

Это доказательство положительного decoded calculus. Корректность Python JSON
parser и его полная эквивалентность Lean checker, lower models, минимальность
horizon, полнота поиска, source-rules, Java frontend и whole-transformer
soundness остаются вне данного утверждения. Native факты пока являются
явными предпосылками, а не доказанными семантическими свойствами программы.

Смешанный `shared_typed` экспортирует ровно 23 положительные из 36 исходных
целей; 13 отрицательных явно учтены как исключённые из формального утверждения.
Все исходные E, узлы и события сохранены. Полный исходный сертификат отдельно
принимается действующим Python checker.

Default SDK и runtime не изменены. Экономический результат PR49 не пересмотрен.
В первом CI изменение самого workflow запустило исторический замер PR49;
фильтр исправлен отдельным commit. На конечном commit старые PR46–49
измерительные workflows не запускаются; результаты первого запуска не
используются как свидетельства PR50.

Этот отчёт и машинные результаты опубликованы отдельным results-only commit
поверх проверенного engine: выпуск отчёта не требует повторять всю CI-матрицу.
