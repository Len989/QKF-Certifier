# QKF Certifier 0.3.0a1 — inferred observations and checked proof composition

This research alpha brings the accepted work through PR51 into a reproducible
release, alongside **Paper III, version 3.0**. It connects source-derived
observations, independent consumer goals and portable checked summaries, and
adds Lean soundness proofs for typed ground DAGs and chronological lemma reuse.

The previous release is [v0.2.0a1](https://github.com/Len989/QKF-Certifier/releases/tag/v0.2.0a1).
The accepted research snapshot is
[`eca90f9252da4480d77c1f8cb4b7062470c57b89`](https://github.com/Len989/QKF-Certifier/tree/eca90f9252da4480d77c1f8cb4b7062470c57b89).
The release preparation changes the manuscript, documentation and version
metadata; the research engines, checkers, formal sources and frozen data are
preserved. The attached provenance record identifies the prepared release commit.

## What changed

- **Source-derived observations and independent targets.** Descending and
  ascending factors are derived from the supported source regions. Independently
  supplied maximum, bound, cyclic-successor and membership goals receive their
  own certificates or checked counterexamples. Typed target formulas, source
  bindings and a unified runner retain separate failure and exhaustion statuses.
- **Word and signed-source coverage.** New profiles cover selected lowest-bit
  expressions, terminal predicates, signed observation inference, a source-bound
  Graal `create` joint-carrier model, and conditional ceiling/caller-invariant
  results. Signed bridges, closed atomic rows and a reusable runtime connect
  independent targets to checked finite source interfaces.
- **Smaller checked interfaces.** Source reduction, live-dependency slicing,
  concrete-witness checking and guarded residual coverage can avoid constructing
  an unnecessary full factor. Checked contexts and shared proof DAGs support
  several consumers without duplicating all retained proof data.
- **Typed proof and summary APIs.** The research layer adds pure-row forcing,
  typed ground-query certificates, guarded native facts, goal-directed questions,
  chronological cross-goal lemmas and an applicable-summary SDK. An admitted
  summary can apply its sufficient action without executing the original source.
- **Measured reuse and direct emission.** Matched SDK comparisons account for
  construction, external cold checking, consumer assessment and export/explanation.
  Prepared immutable contexts reduce repeated admission work. Direct emission
  produces the final dependency DAG from checked producer state while retaining
  independent public replay and the same canonical delivery/result bytes.
- **Two new Lean kernels.** `formal/ground` proves soundness of positive typed
  ground DAGs. `formal/composition` proves chronological lemma import, exact
  premise/residual binding and equality of actual typed consumer values. Both
  pin Lean 4.33.0 / Std, audit axioms and include rejection/integrity controls.

## Results and interpretation

**Ordinary SDK is QKF's own implementation.** The ordinary closure route and the
query-directed route share the checked SDK delivery contract. In the registered
PR47–49 development comparisons, the ordinary SDK remains the less costly
matched control. This is an internal implementation comparison.

PR49 direct emission reduces query/no-lemmas lifecycle medians by **27.96–38.80%**
relative to PR48 across ten positive case/environment comparisons. The range
summarizes separate measurements, not a pooled estimate or confidence interval.
Across 42 matched PR48/49 comparisons (40 positive and two fallback), the
canonical delivery/result bytes agree. The unchanged ordinary SDK control is
still cheaper than all four new factors in the ten positive environments.
The two fallback comparisons do not show a lifecycle improvement. See the
[registered PR49 report](https://github.com/Len989/QKF-Certifier/blob/eca90f9252da4480d77c1f8cb4b7062470c57b89/research/direct_emission/REPORT_RU.md)
for raw-result references and complete cost definitions.

The retained KnownBits results remain **11/39 complete programs** and
**104/411 components**. External frozen studies retain their own denominators:
**1/15** for the inference-v2 holdout and **2/33** for frozen inference v3.
The latter positives share one algorithm body. Unavailable contracts and target
language gaps are recorded as capability gaps; repeated runs do not increase
program coverage.

The new formal ground fixtures contain **9 positive DAGs / 32 goals** and
**28 negative DAGs**. Composition contains **12 positive packets / 56 consumers**
and **17 negative packets**, including original direct-SDK packets from PR49.
The theorems concern decoded typed structures under explicit native assumptions.
They do not verify the Python JSON decoder, Java frontend, source-rule library,
search completeness, minimum proof horizons or whole-transformer execution.

## Installation and assets

- `qkf_certifier-0.3.0a1-py3-none-any.whl` and `qkf_certifier-0.3.0a1.tar.gz`:
  the coordinatewise Python application, Python 3.10+, no runtime dependencies.
- `QKF_CERTIFIER_0.3.0a1_RESEARCH_SOURCE.zip`: complete research, formal projects,
  papers, frozen inputs and repository tools.
- Paper III v3.0 PDF and LaTeX archive: the integrated scientific account.
- `CHANGES_v0.3.0a1.md`, `VALIDATION_0.3.0a1.md`, provenance and SHA-256 files:
  complete change history, exact validation scope and asset identities.

```sh
python -m pip install qkf_certifier-0.3.0a1-py3-none-any.whl
qkf --version
```

The installed CLI retains AND/OR/XOR target scope, the existing Python API,
runtime semantics and `qkf-rewrite-v3` certificates. The new research SDKs are
included in the full research archive, not in the wheel. No PyPI publication
is implied by this GitHub release.
