# QKF → AI: исполнимые интерфейсы и проверяемые действия

Дальний ориентир — автоматически получать достаточный исполнимый интерфейс к новому окружению, применять его к новым программам и подтверждать пользу относительно сильного обычного решения с учётом затрат обучения и исполнения. Номера опытов из чата независимы от PR и других research profiles QKF-Certifier.

**Run27 завершён:** [отчёт и план развития](run27/REPORT_RU.md), [независимый разбор](run27/REPORT_REVIEW_RU.md), [зафиксированный протокол](run27/PROTOCOL_RU.md). Локально и в GitHub Actions — по 192 целые записи, 144/144 основные цели, 24 ожидаемых отказа при неверных знаниях. Использование двух законов эффектов подтверждено в ограниченном логическом домене; оба зарегистрированных порога экономии FAIL. На длинном transfer portfolio преимущество бесплатного oracle над сильным ordinary всего 1,74%. LLM-эпизодов нет.

Наш обычный SDK получил полезное улучшение: учится во время первой настоящей задачи и повторно использует знания. Это сокращает цену получения двух фактов с 11 единиц отдельной пробы до 5 дополнительных единиц в среднем. Единицы здесь синтетические API charges, не деньги или полная цена разработки. Обычное решение остаётся частью нашего продукта.

Модули продукта: адаптер действий и наблюдений; представление состояний/предикатов/эффектов со scope и evidence; генератор различающих вопросов и контрпримеров; проверяющий слой; планировщик; исполняющий SDK с recovery/idempotency; журнал и независимый evaluator; интерфейс человека. Run27 проверяет небольшой работающий фрагмент, а не готовность всех модулей. Формальные гарантии QKF-Certifier автоматически не распространяются на эмпирические API-законы.
