# Единый явно объявленный контракт

Для любого w>=1 слова имеют w бит; width=w представим при каждом таком w.
Вход KnownBits — (Z,O), Z&O=0. Конкретное a совместимо, если a&Z=0 и a&O=O.
Для двух совместимых входов a,b вычисляется y=target(a,b). Выход исходного
solution=(Zo,Oo) корректен, если y&Zo=0 и y&Oo=Oo. SMT ищет нарушение этого
свойства без изменения исходного solution.

Модульная арифметика и литералы усечены по 2^w; neg означает побитовое NOT.
clz/clo/ctz/cto возвращают w на полном соответствующем слове. Установка и
сброс k крайних битов ограничивают k сверху шириной. Логический сдвиг на k>=w
даёт 0, арифметический — заполнение знаком. Деления тотальны: udiv(a,0)=ones,
urem(a,0)=a; sdiv(a,0)=1 для отрицательного a, иначе ones; srem(a,0)=a.
Знаковое деление округляется к нулю, остаток имеет знак делимого. Это прежний
математический QKF-контракт, не вся LLVM poison семантика.

| Семейства имён | Цель |
|---|---|
| And, Or, Xor | Побитовые AND, OR, XOR |
| Add*, Sub*, Mul | Сумма, разность, произведение по модулю 2^w |
| Umin, Umax, Smin, Smax | Беззнаковый / знаковый минимум и максимум |
| UaddSat, UsubSat | Беззнаковое насыщение в [0,2^w-1] |
| Shl*, Lshr*, Ashr* | Тотальные сдвиги, описанные выше |
| Udiv*, Sdiv*, Modu, Mods | Тотальные udiv, sdiv, urem, srem |
| Abdu | Модуль беззнаковой разности |
| Abds | Модуль разности знаковых значений, затем усечение до w бит |
| AvgFloorU/S, AvgCeilU/S | Полусумма математических unsigned/signed значений с округлением вниз/вверх |
| UshlSat | a*2^b с насыщением в unsigned диапазоне |
| SshlSat | signed(a)*2^b с насыщением в signed диапазоне |

Звёздочка обозначает также имена с флагами. Нулевое число при saturating shift
остаётся нулём при любом сдвиге. Указанные дополнительные цели полностью
определены независимо в target_contract.concrete и smt_encoder.target;
они не подаются старому QKF backend, если отсутствуют в его target_for.
Совпадение этих двух определений проверено для всех a,b при w=1..4 и
случайных 32-битных пар. Это конечная проверка кодировки, не формальная
верификация адаптера и не аудит соответствия оригинальным LLVM спецификациям.

27 файлов без суффиксов флагов и 12 с флагами публикуются раздельно. Кроме
того, результаты помечены как 16 прежних целей и 23 вновь объявленных целей
finite benchmark. Такое расширение измерения не меняет исторический знаменатель
39 и не создаёт дополнительных доказанных QKF-программ.
