## Восстановить текущий проект

После распаковки этого ZIP перейти в его каталог и выполнить:

```bash
python restore_project.py
python freeze_result_v2.py
python audit_result_v2.py
```

Первая команда восстанавливает точные неизменённые исходники и обе статьи
из включённого предыдущего архива, затем все результаты, тесты и неудачи
из EXPERIMENT_DATA.tar.xz. Все байты проверяются; различающиеся локальные
файлы не перезаписываются. Нужен только Python 3.12 и стандартная библиотека,
сеть и другие архивы не требуются.

5. 05_NEXT_STEPS_RU.md — что делать дальше.

Первые две статьи полностью сохранены в papers/paper_I и papers/paper_II:
исходники, PDF, карты утверждений и собственные проверки. Их текст не менялся.

## Действующие точки входа

- result_kernel.py и result_stage_kernel.py — проверка наблюдений и
  доказательство исходной программы.
- result_v2_producer.py и result_v2_stage_producer.py — исправленный поиск.
- result_v2_run.py — свежие процессы и строгая блокировка поиска в replay.
- validate_result.py — 304 семантических случая и отрицательные проверки.
- validate_result_v2.py — шесть случаев технической регрессии producer.
- audit_result_v2.py — аудит итогового results_v2.

Повтор одного случая в новом каталоге:

```bash
python result_v2_run.py --mode observed --case KnownBits_Add --output reproduction/add
```

Все режимы можно повторить result_v2_run.py, указав baseline, sign,
observed и разные новые каталоги. Итоговые файлы защищены от перезаписи.
run_result_v2_experiment.py относится к первоначальному запуску; его
results_v2 уже заполнен. При повторе нельзя затирать сохранённый эксперимент.
