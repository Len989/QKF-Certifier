# QKF: нижняя граница, 13 сентября 2026

Продолжение `QKF_UNIVERSAL_UPPER_2026-09-13.zip`. Автор проекта — Леонид Щербаков.
Этот пакет сохраняет точный предыдущий архив, всю предшествующую историю,
обе исходные статьи и результаты неудачных попыток текущего этапа.

Результат: универсально доказано восстановление следующего масочного слова
при переносе. Для настоящего Graal `computeLowerBound` доказано сохранение
совместного носителя при совместимых масках, типизированной границе и условии
`lowerBound <= 0 || may-sign-bit == 0`.

Это не универсальная теорема о точном минимуме отдельно взятого helper.
Такое утверждение оказалось ложным. Контрпримеры сохранены. В доказанной
области helper иногда выдаёт корректную, но неточную нижнюю границу.
Подготовка входов вызывающим `create` ещё не доказана целиком.

Начать с `REPORT_RU.md`, затем `THEORY_RU.md` и `05_NEXT_STEPS_RU.md`.
Код нового этапа — в корне; неизменённый рабочий предыдущий этап — `previous/`.
Для восстановления распакованного пакета и проверки доказательств:

```bash
python restore_project.py
python replay_saved.py --output reproduction/check_01
python audit_step.py --output reproduction/audit_01.json
```

Нужен обычный Python 3.12 без `-O`. Для replay не нужны сеть, SMT, JDK или ECJ.
Имена выходных каталогов должны быть новыми. Нативные исполняемые зависимости
нужны только для повторения Java-экспериментов; сведения о версиях сохранены.

После восстановления обе статьи доступны в `papers/` — 93 файла.
`PACKAGE_MANIFEST.json` и `DATA_MANIFEST.json` связывают все байты пакета;
`PAPERS_INHERITANCE.json` описывает проверяемую цепочку точных архивов.

Покрытие целых программ: Graal control 1/5, joint 2/5 (AND, OR); исторический
NiceToMeetYou 11/39 и 104/411 компонентов. На этом этапе эти числа не выросли.

Рабочий принцип пользователя сохранён в `PROJECT_PRINCIPLES_RU.md`: сначала
искать решения через общую теорию двух статей, наблюдения, вынужденные строки,
ядра и согласованную склейку; честно обозначать добавленные семантические мосты.
