# QKF: универсальная верхняя граница

Состояние на 13.09.2026. Автор проекта — Leonid Shcherbakov.
Прогон по запросу «Попробуй универсализировать» завершён.

**Один сертификат теперь доказывает контракт всей процедуры
Graal computeUpperBound по всем совместимым маскам, всем верхним границам
и обоим вариантам canBeZero.** Он параметричен по любой положительной
ширине математической модели. Для исходного Graal сохраняется область
поддерживаемых ширин 1,8,16,32,64.

Это контракт одной процедуры уточнения, включая реальное сужение
масочного носителя, знак и пустоту. Полный create и универсальность QKF
для всех SMT-задач здесь не получены. Прежний Graal-набор повторён:
контроль 1/5, совместная версия 2/5. Исторический NiceToMeetYou остаётся
11/39 и 104/411; нового SMT-сравнения нет.

После распаковки внешнего ZIP выполните рядом с этим файлом:

```bash
python restore_project.py
python audit_step.py --output reproduction/audit.json
python replay_saved.py --output reproduction/strict
```

Достаточно обычного Python 3.12, без `-O`/`-OO`, без JVM, сети и решателя.
Вернутся текущий проект и все 93 файла обеих статей. Предыдущий полный
архив сохранён побайтно в prior_stage вместе со всей вложенной историей.
Проверки восстановления и повторного доказательства — в RESTORE_CHECK.json.

Порядок чтения:

1. `PROJECT_PRINCIPLES_RU.md` — приоритеты пользователя и цель проекта.
2. `REPORT_RU.md` — что именно универсализировано, результаты и ограничения.
3. `THEORY_RU.md` — проверяемая связь со статьями, инвариант и доказательство.
4. `papers/` — исходные две статьи и прототипы, восстановленные из истории.
5. `05_NEXT_STEPS_RU.md` — следующий исследовательский шаг.
6. `REPRODUCE_RU.md`, `IMPLEMENTATION_LOG_RU.md`, `audit/AUDIT.json` —
   команды, история разработки и учёт результатов.

Главные новые файлы: row_kernel.py, sweep_kernel.py, source_contract.py,
order_kernel.py, universal_kernel.py, universal_api.py. Производители
сертификатов отделены от replay. Зафиксированный основной результат —
`results/main/universal_upper/`; исходник Graal —
`baseline/source/IntegerStamp.java`.

Все 343 унаследованных файла сохранены по хешам. Перед основным прогоном
зафиксировано 428 файлов development-версии. Текущие отчёты, аудит и
упаковка добавлены после фиксации; зафиксированный код не менялся.
