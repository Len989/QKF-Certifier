# QKF: совместный носитель маски, диапазона и нуля

Состояние на 13.09.2026. Автор проекта — Леонид Щербаков.
Этот прогон завершён. Начинать следующий следует с 05_NEXT_STEPS_RU.md.

## Восстановление

Распакуйте внешний ZIP и в каталоге рядом с этим файлом выполните:

```bash
python restore_project.py
python audit_step.py --output reproduction/audit.json
python replay_saved.py --output reproduction/strict
```

Обычного Python 3.12 достаточно; не запускайте с `-O`/`-OO`.
Восстановление проверяет хеши, возвращает текущие исходники, все результаты
и 93 файла обеих первых статей. Полный предыдущий архив сохранён побайтно
в `prior_stage/`, вместе со всей более ранней историей. Установленные JVM
и решатель не включены; они не нужны для этих трёх команд.

## Что изменилось

- Общий сертификат совместного наблюдения маски, знакового диапазона и
  запрета нуля. Он отвечает о бите, пустоте, точных границах, маске,
  количестве слов и единственном слове, если оно вынуждено.
- Общая проверяемая лемма для исходного Graal `create`, когда диапазон
  содержит весь масочный носитель и ноль разрешён. Она открыла полный
  масочный результат AND на нашем KnownBits-контракте.
- На пяти сохранённых процедурах Graal: контроль **1/5**, новая версия
  **2/5** (AND, OR). XOR, ADD, SUB остаются неподдержанными. Это разработка
  на известном материале, не свежий holdout.
- Построена настоящая конечная инстанция статей I–II: защищённый носитель
  из 4 элементов, вынужденная строка, ядро из 2 классов, видимость 2 и
  разделяющая модель из 7 элементов для горизонта 1.
- После основного прогона найден полезный диагностический пример:
  полный stamp Graal представляет только −127 и 1, но его отдельная
  маска не показывает их общий младший бит. Совместный запрос QKF его
  доказывает; множество представленных слов остаётся тем же.

Старые числа NiceToMeetYou — **11/39 полных**, **104/411 компонентных** —
сохранены без нового прогона. Прежние SMT 29/40 UNSAT и 11 тайм-аутов тоже
сохранены, нового сравнения с SMT здесь нет.
