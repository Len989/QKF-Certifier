# Проверка и воспроизведение

Использован Python 3.12 на Linux x86_64. Команды ниже выполняются в каталоге
рядом с этим файлом. Все новые результаты пишутся в новые каталоги;
повторно укажите другое имя, если оно уже занято. Не используйте Python
`-O`/`-OO`: часть исторических проверяющих использует assertions.

## Проверка сохранённого результата

```bash
python restore_project.py
python audit_step.py --output reproduction/audit.json
python replay_saved.py --output reproduction/strict
```

Первая команда возвращает текущие файлы и обе статьи из включённой истории,
проверяя SHA256 и размеры. Она не перезаписывает отличающиеся файлы; при
повторе проверяет уже восстановленные. Аудит подтверждает 201 неизменный
унаследованный файл и 281 файл development-фиксации, все знаменатели и
связи сертификатов. Последняя команда запускает пять свежих процессов:
три связки Java→наблюдение→SSA→целое слово, 28 совместных сертификатов
и двусторонний ground-сертификат статьи II. Поиск и SMT при replay блокируются.

Для этих проверок JVM, ECJ, Z3 и сеть не нужны. Результат чистого
восстановления перед передачей записан в RESTORE_CHECK.json.

## Повторное производство

```bash
python reproduce_main.py --output reproduction/main
```

Будут заново выполнены все пять слотов control и joint, а затем строгая
проверка. Это повтор известного development-набора, не новый holdout.
Не запускайте `step_run.py` без аргументов поверх сохранённых `results`:
исходный runner намеренно отказывается затирать файлы.

Малую и широкую семантическую валидацию можно воспроизвести отдельно:

```bash
python -c 'from pathlib import Path; from validate_joint import run; run(Path("reproduction/joint_validation"))'
```

Конечная инстанция статьи II заново производится так:

```bash
python -c 'from pathlib import Path; from theory_certificate import create; print(create(Path("reproduction/theory")))'
```

`theory_certificate.py` без аргументов проверяет уже сохранённое доказательство.

## Необязательное повторное исполнение Java

Использован jdk4py 25.0.2.1 и ECJ 3.42.0. Точные URL и SHA256 входят в
source/JDK_INSTALL.json и native/MANIFEST.json. Можно установить их в новый
каталог с доступом к сети:

```bash
python reproduce_tools.py --directory ../qkf_graal_tools
```

Если JVM уже доступна по другому пути, задайте `QKF_JAVA_RUNTIME` абсолютным
путём к её каталогу `java-runtime`. `native_java.py` сам задаёт пути к
библиотекам этой JVM. Исполняемые классы точных извлечённых тел уже включены
в пакет и проверяются манифестами; это не полный Graal build.

```bash
python -c 'from pathlib import Path; from validate_source_bridge import run; run(Path("reproduction/source_validation"))'
```

Эта проверка повторяет 25 454 вызова `create`, 17 320 сопоставлений AND/OR
и source-мутации. Запуск `native_java.py` как главного скрипта переписывает
генерируемый native-каталог, поэтому не выполняйте его в зафиксированном
пакете. Для пересборки скопируйте проект в отдельную development-директорию
и сохраните новый манифест компиляции.

Постэкспериментальные сертификаты неявного бита включены в `postrun` и
повторно проверяются аудитом. Повтор самого Java-примера ширины 8:

```bash
python -c 'from native_java import evaluate; print(evaluate(["create 8 -127 1 0 81 0"])[0])'
```

Ожидаемый ответ: `OK -127 1 0 81 0`. `may=81` здесь в шестнадцатеричной
записи. Точный совместный носитель — {-127,1}, его `must=1`.

## Полнота истории

Внешний архив содержит точный QKF_GRAAL_TRANSFER_2026-09-13.zip. Его SHA256:
`61720068a6c58b5e85cd6d7d11b1374ade72a0689de417eb8719863131e65e72`.
Внутри сохраняются точные предыдущие архивы, исходные статьи и прежние
эксперименты, включая SMT-файлы, тайм-ауты и неудачные версии. История не
сведена к итоговой таблице. Для обеих статей восстановитель проходит
проверенную цепочку Graal→Result Observations→Context Observations.

Текущие данные упакованы в EXPERIMENT_DATA.tar.xz; DATA_MANIFEST.json
перечисляет их. PACKAGE_MANIFEST.json описывает внешние члены пакета;
PAPERS_INHERITANCE.json — точные 93 файла статей и цепочку их происхождения.
Python-восстановитель проверяет пути и отказывается от ссылок и подмен.

Повторная сборка полного пакета из восстановленной директории:

```bash
python build_package.py --prior prior_stage/QKF_GRAAL_TRANSFER_2026-09-13.zip --output ../QKF_JOINT_CARRIERS_REBUILT.zip
```

Имя результата должно быть новым. Контрольные суммы самого ZIP могут
отличаться из-за метаданных архива; все включённые исходники, доказательства
и точный предыдущий архив остаются проверяемыми побайтно.
