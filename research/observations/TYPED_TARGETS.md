## Контракт

`qkf-word-observation-spec-v1` описывает внешний профиль, фиксированный
входной носитель, универсального допустимого конкурента, дополнительные
предусловия и обязательства. Компилятор выводит конечные наблюдения из формулы.
Проверяющий заново компилирует внешнюю цель, а не доверяет программе из пакета.

Профили источника различны: `ascending` выдаёт биты; `descending` распознаёт
граф входа/выхода и использует отдельное отвергающее состояние. Незаконный
выход нельзя исключить из алфавита вместо доказательства его допустимости.
Начальное пустое слово отличается от слова положительной длины.

Грамматика слов: переменные профиля, `zero`, `ones`, `bit_not`, `bit_and`,
`bit_or`, `bit_xor`. Предикаты: `eq`, `ne`, `ult`, `ule`, `ugt`, `uge`,
`subset`, `disjoint`. Связки: булевы литералы, `not`, `and`, `or`, `implies`.
Порядок беззнаковый; новый старший различающийся бит определяет сравнение.

Предусловия могут читать только входы, не `output` или `alternative`.
Их выполнимость НЕ доказывается: противоречивое предусловие даёт условно
истинное утверждение, а не доказательство существования допустимого входа.
Лимиты синтаксиса: 512 узлов, глубина 16, 16 наблюдений. Неподдержанная
формула или исчерпание бюджета не означают опровержение исходной программы.

## Использование

Из корня репозитория, с новыми путями вывода:

```sh
python -m research.observations.run spec changes.goal.json --profile ascending --claim changes --language observations
python -m research.observations.run verify research/graal/native/IntegerStamp.java --profile ascending --spec changes.goal.json --output reproduction/changes_01
python -O -m research.observations.run check research/graal/native/IntegerStamp.java --spec changes.goal.json --package reproduction/changes_01/package.json
```

`changes` означает: при наличии необязательных битов выход допустим и
отличается от начального слова. Это более слабое требование, чем преемник.
Также есть шаблоны `maximum`, `bound`, `cyclic_successor`, `membership`.
Разрешены другие формулы в указанной грамматике; имя шаблона не выбирает
особый проверяющий. `spec` создаёт только шаблон, не доказательство.

Старые спецификации, команды и пакеты v1 не меняют смысла. Новый маршрут
имеет оболочку `qkf-research-package-v2`. При повторной проверке исходник
и спецификация передаются независимо. Контрпример повторно проверяется
фактором источника, целочисленным исполнением и числовым смыслом формулы.

## Сохранённые доказательства и свежий поиск

Снимок `evidence/typed_targets/SNAPSHOT.json` содержит все 23 целевых
сертификата. Общие исходники и сертификаты источников берутся из уже
версионированных каталогов `ascending` и `property`; пять программ наблюдений
и пять целей хранятся по одному разу. Это обычные JSON-данные, не архив кода.
Каждый полный пакет восстанавливается с прежним каноническим SHA-256 и
проходит оба проверяющих. Хеш не заменяет доказательство.

```sh
# Только повторная проверка: поиск не импортируется.
python -O -m research.observations.target_evidence reproduction/typed_retained_01
# Новое построение из исходников, затем сравнение с прежними пакетами.
python -m research.observations.run_target_experiment reproduction/typed_fresh_01
python -O -m research.observations.run_target_experiment reproduction/typed_fresh_01 --replay
python -O -m research.observations.target_evidence reproduction/typed_fresh_01 --compare-fresh
```

18 переведённых целей дают 11 доказательств и 7 контрпримеров; пять `changes`
дают 3 доказательства и 2 контрпримера. Это девять прежних вариантов исходников,
не новый внешний корпус и не 23 различных алгоритма.

## Проверки и границы

Workflow `Typed targets and existing Lean regression` запускает весь набор
наблюдений в обычном Python и под `-O` на Python 3.10/3.12, заново получает
23 пакета и проверяет неизменность 18 прежних v1-пакетов. Тесты включают
исчерпание бюджета, подмену целей и источника, повреждение пакетов после
пересчёта хешей, полноту колонок и числовые проверки правил.

Отдельное задание повторяет принятый PR №8: свежая Lean-сборка, аудит
10 теорем и шесть отрицательных контролей. Это регрессия уже принятой
формализации, а НЕ новый источник→экспортёр→Lean маршрут и НЕ доказательство
корректности произвольного JSON-компилятора. Экспортёр остаётся вне PR.
Статусы настоящего CI относятся к конкретному опубликованному коммиту;
наличие workflow само по себе не означает успеха.

Ограниченные фронтенды, правила срезов и Python-правила целей остаются
доверенными. Не заявляются полный Java-метод, знаковая JVM-семантика для
произвольных входов, `IntegerStamp.create`, композиция или расширение
устанавливаемого пакета `qkf`. Автоматическое слияние не выполняется.
