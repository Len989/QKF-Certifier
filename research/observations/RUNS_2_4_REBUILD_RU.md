## Чего эта поставка не утверждает

Новый CI на Python 3.10/3.12 **не запущен**. Lean/Lake здесь отсутствуют:
новая сборка Lean, настоящий аудит аксиом и отрицательные Lean-контроли
в этом возобновлении **не выполнены**. Успех №8 остаётся историческим
результатом для сохранённых математических файлов. Hypothesis, Ruff,
сборка дистрибутива и весь комплект публичных тестов отдельно здесь не
повторялись; существующие workflow main их предусматривают после публикации.

Новый workflow требует свежую генерацию пакетов, проверку точного экспорта,
чистую Lean-сборку, 10 записей аудита и 6 отрицательных контролей. Он допускает
приёмку только при `status: accepted` и `lean_checked: true`; наличие YAML
не считается выполнением этих проверок.

Область математических гарантий остаётся прежней: ограниченные профили
словных программ, явно заданный фактор и числовые цели. Парсер Java,
Python-реализация, JSON-трансляция и экспортёр не становятся Lean-проверенными.
Новая теорема о полном Java-методе или композиции не заявляется.

## Повторение после применения патча

Из корня полной копии:

```sh
python -m unittest discover -s research/observations/tests -v
python -O -m unittest discover -s research/observations/tests -v
python -m research.observations.run_target_experiment reproduction/typed24_fresh
python -O -m research.observations.run_target_experiment reproduction/typed24_fresh --replay
python -O -m research.observations.lean_target_export research/lean_targets/evidence --check
```

В окружении с закреплённым Lean 4.33.0:

```sh
python -O -m research.observations.run_lean_target_validation \
  --output reproduction/typed24_lean --timeout 300
```

Все каталоги нового вывода должны быть новыми. Прогон 3 для этих команд
не нужен. Публикация и приёмка CI остаются обязательствами будущего PR.
