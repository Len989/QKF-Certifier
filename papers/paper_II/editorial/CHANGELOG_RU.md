# Статья II: содержательные изменения

Редакция 12 сентября 2026, препринт v1.0. Исходная загруженная рукопись не изменена. Переписан английский текст; общая линия согласована со статьёй I, v1.0 от 11 сентября 2026.

## Главное математическое исправление

Прежняя статья определяла ограниченное равенство через конгруэнцию частичной алгебры термов, а затем отождествляла его глубину с максимальной длиной промежуточного слова в последовательном полугрупповом выводе. Это отождествление неверно.

Для E = {p = f²(r), q = f²(r)} равенство f(p) = f(q) имеет глубину 2 в конгруэнционном доказательстве: сначала p = q, затем конгруэнция. Последовательное переписывание должно пройти через f³(r), поэтому его глубина равна 3. Это также показывает, почему ground-locality не переносится на переписывания.

В полугрупповой презентации ⟨p,x,y,z | x = zzzz, y = zzzz⟩ пара цепочек для px и py имеет конгруэнционную глубину 4, но последовательное пространство 5. Следовательно, прежняя точная формула для чистых цепочек действительно ложна для lambda без уточнения формата. Оба контрпримера включены в PDF и проверены независимо через ограниченную достижимость.

Новая редакция использует:

- lambda и delta — конгруэнционные доказательства с повторным использованием уже установленных равенств;
- lambda^rw и delta^rw — последовательные переписывания с ограничением глубины каждого целого промежуточного терма.

Всегда lambda ≤ lambda^rw и delta ≤ delta^rw. Неограниченная теория равенства у них одна. Точное соответствие с полугрупповым пространством, формула контекстной оболочки и перенос результатов реализации теперь утверждаются для delta^rw. Для delta общий полугрупповой профиль здесь не установлен. Контрпример опровергает старое попарное отождествление; он сам по себе не объявляется опровержением любой возможной асимптотической связи глобальных функций.

## Сохранённые и усиленные результаты

Все 21 утверждение исходной статьи имеют соответствующее место в новой редакции; карта находится в THEOREM_MAP.md. Ground-locality, каталановский спектр, query-subterm theorem, first-merge characterization и модель нижнего горизонта сохранены для конгруэнционной глубины. В доказательстве реализации каталановских профилей явно объяснено повторное использование равенства вместо переноса всего свидетеля в контекст.

Добавлено Proposition 3.4: конечное ground-представление можно расширить конечным набором истинных равенств так, чтобы delta(d) = d на всех слоях. Поэтому прежний вопрос о существовании такой конечной нормализации заменён вопросом о её размере и стоимости.

В Theorem 4.1 дано прямое доказательство через конечную модель классов. Обработаны пустой query set и пустые активные сорта. В доказательствах сертификатов разделены три вещи: хронология обеспечивает ацикличность; полное насыщение на первом горизонте обеспечивает оптимальную верхнюю границу; модель предыдущего горизонта или глубина концов даёт нижнюю границу. Положительное доказательство само по себе не удостоверяет минимальность.

Уточнены значение lambda(t,t) = dep(t), неультраметрическая нулевая диагональ, различие между наблюдаемыми фактор-множествами и полными подалгебрами, а также поправка delta(d) = max(d, delta(T^(d))) для вырожденной сигнатуры без термов точной глубины d.

Theorem 7.2 о вычислимости расширена на обе величины. Глубина сохраняющих тождеств даёт немедленную точность также для обеих величин.

## Связь с первой и третьей статьями

Введена библиографическая ссылка на точную редакцию I без выдуманного DOI. Добавлен общий пример I, Example 6.2: N1 = 5, N2 = 3, carrier-классы {0,2}, {1}, {3}. В PDF есть явные доказательства двух поздних равенств, пятиточечная модель нижнего горизонта и трёхточечная полная модель.

Ссылки на I, Theorem 6.6 и Proposition 5.5 проверены по новой редакции. Query set обозначается каллиграфической Q, а Q_E сохраняется для carrier quotient. Число feedback-итераций не отождествляется с синтаксической глубиной.

Статья III обозначена как планируемая. Этот пакет не изменяет репозиторий QKF-Certifier и не приписывает ему вычисление универсальных пространственных инвариантов. Заметка III_IMPLICATIONS_RU.md фиксирует нужные изменения прежнего плана серии.

## Вычислительная часть и библиография

Вместо исторической таблицы времени включены результаты свежих воспроизводимых запусков. Проверены все 195 каталановских профилей при h ≤ 5, 14 расширений для устранения overhead, общий пример, пять профилей action laboratory и два контрпримера. Регрессионные проверки охватывают реализации замыкания, доказательства, конечные модели и уровни слияний; точные числа приведены в verification/README.md.

Прототип скопирован из исходного приложения. Из него удалены устаревшие абсолютные пути; не заявлено, что он стал новой версией публичного инструмента. Его внутренние проверки объяснений не являются самостоятельным форматом внешних сертификатов. Общие теоремы не формализованы в proof assistant.

В полугрупповой части проверены первичный текст Olshanskii и Corollaries 1.4–1.6. Недоступная для первичной проверки недавняя ссылка Kalampakas удалена как необязательная для результатов; выводов о её достоверности не делается. Неиспользуемые исторические ссылки сокращены. DOI статьи I и III отсутствуют, поскольку реальные идентификаторы не были предоставлены.
